# WORKの追加手順

- 完成作品シートから、掲載用作品名、クライアント名、web 入力済みかどうか、区分・元の作品名・ジャンル、素材や投稿のリンク、公開日、担当者を確認する。既存作品との重複も調べる。
- 素材・投稿リンクを開き、作品名・内容・公開日と一致するか確認する。誤リンクや取得できない素材を別作品として登録せず、行番号と不足情報を追加位置に TODO で残す。
- 主な制作物に応じて `src/data/work/design.ts`、`video.ts`、`music.ts`、`service.ts` の既存形式に追加する。`src/types/work.ts` の `Work` に合わせ、日付は `YYYY-MM-DD`、タグと担当者はシートの内容を使う。X 投稿は `tweet`、YouTube 動画は `video` アセットにする。
- 直接取得できる画像は WebP に変換し、`src/assets/works/YYYY/MM/YYMMDD_種類_内容.webp` に置いて import する。元画像と変換後の画像を開き、内容・寸法・形式を確認する。X 投稿のサムネイルは投稿 URL だけでは生成されないため、必要なら別途画像を用意して `thumbnail` に指定する。
- 追加後は上記のチェック・整形・Lint とビルドを実行し、作品カードと詳細表示を確認する。依頼がない限り、シートの「web 入力済み」は変更しない。
